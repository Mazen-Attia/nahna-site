Häufige Fragen

Wie verbinde ich mich mit meinem Partner?
Eine Person tippt Code erstellen und schickt den Code, die andere tippt Ich habe einen Code und gibt ihn ein.

Kann jemand meine Nachrichten lesen?
Nein. Nachrichten, Fotos, Briefe und Pläne werden auf eurem Handy verschlüsselt. Auch wir können sie nicht lesen.

Wie beende ich eine Verbindung?
Einstellungen → Verbindung beenden. Der alte Code funktioniert danach nicht mehr.

Wie lösche ich mein Konto?
Einstellungen → Konto löschen. Alles, was du geschrieben oder geschickt hast, wird sofort gelöscht.
